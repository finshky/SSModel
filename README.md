# SSModel

**SSModel** is a Mathematica package for computing gravitational-wave (GW) spectra sourced by acoustic oscillations following cosmological first-order phase transitions, based on the **sound-shell model**.

The package implements the framework described in [arXiv:1909.10040](https://arxiv.org/abs/1909.10040) and [arXiv:2308.12943](https://arxiv.org/abs/2308.12943).

It also includes **`SSModel_2f.wl`**, an extension to a two-fluid scenario in which sound waves generated by a phase transition in a dark sector can transfer energy into the visible sector through weak interactions between the two fluids.

## Package structure

```text
SSModel/
├── SSModelBubbleFluidProfiles.wl
├── SSModel.wl
├── SSModel_2f.wl
└── data/
    ├── kinetic.wl
    ├── gw.wl
    └── gw.2f.wl
```

## Main functions

### `Profile`

Computes the fluid profiles around expanding phase-transition bubbles, including:

- Fluid velocity
- Enthalpy
- Energy-density perturbations

### `GetKineticSpecrum`

Computes the dimensionless kinetic spectrum, (\zeta\_{\mathrm{kin}}(K)), following Eqs. (33) and (41) of [arXiv:2308.12943](https://arxiv.org/abs/2308.12943).

If the requested spectrum is not already available in `data/kinetic.wl`, it is computed and stored for subsequent use.

### `OmegaGW`

Computes the gravitational-wave spectrum, (\Omega\_{\mathrm{GW}}(K)), following Eq. (51) of [arXiv:2308.12943](https://arxiv.org/abs/2308.12943).

### `OmegaGW2f`

Computes the gravitational-wave spectrum in the two-fluid scenario, following Eq. (45) of *Leaking Sound Waves: GWs From Dark Sectors Weakly Coupled to the SM*.

The two-fluid extension introduces two additional parameters:

- **Interaction rate:** (\gamma \equiv \Gamma\_{\mathrm{int}}/H\_*), where (\Gamma\_{\mathrm{int}}) is the interaction rate between the fluids and (H\_*) is the Hubble parameter at the phase transition.
- **Enthalpy ratio:** (r_w \equiv \bar{w}\_v/\bar{w}\_d), where (\bar{w}\_v) and (\bar{w}\_d) are the background enthalpy densities of the visible and dark fluids, respectively.

## Numerical performance and Python implementation

The Mathematica implementation can be computationally expensive in certain parameter regimes. In particular, numerical integrations performed using Mathematica's `NIntegrate` may take a considerable amount of time to converge.

To provide an alternative for these cases, this repository also includes the Python script **GW_models_2f.wl**, Python script extending [`cosmoGW`](https://github.com/) to the two-fluid scenario. This implementation provides an additional route for computing the gravitational-wave spectrum when the Mathematica calculations become prohibitively slow.
